# Kaucjowicze

Kaucjowicze is a simulation of agents collecting deposit-return cans across the AGH Student Campus (Miasteczko Studenckie AGH) using Ant Colony Optimization (ACO). Agents carry cans back to a collection point and leave pheromone trails that lead others to areas with many cans, and we compare this approach against a random-walk baseline. The project is written in Python with NumPy, uses Pygame for visualization and pandas for analyzing results stored in CSV files.
